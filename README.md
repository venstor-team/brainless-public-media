# brainless-public-media

Médias **destinés à la publication** sur les réseaux de Brainless (Instagram, Facebook, X).
Servis par GitHub Pages pour que OneUp puisse les récupérer par adresse.

⚠️ Dépôt **public**. N'y mettre que du contenu prêt à être publié.
Aucun document client, aucune donnée interne, aucun brouillon.

Adresse de base : `https://venstor-team.github.io/brainless-public-media/`
